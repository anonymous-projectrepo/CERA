Summary

Abstract

Vision-language-action (VLA) models rely on large multimodal backbones whose computation and memory requirements can make fully onboard deployment difficult on resource-constrained robots. Moving the entire policy to the cloud reduces this onboard burden, but also makes action generation dependent on remote inference and communication. A cloud-edge split therefore provides an attractive alternative: the computationally expensive vision-language model (VLM) is executed in the cloud, while the action head remains on the robot for local action generation. However, this deployment requires repeated transmission of high-dimensional intermediate representations from the VLM to the action head, creating a substantial communication burden. We introduce CERA, a Communication-Efficient Refinement Adapter that reduces this communication cost without modifying the pretrained VLA components. CERA preserves a compact base representation across the VLM output and selectively refines semantic tokens according to their predicted contribution to preserving the original policy's actions. Refinement priorities are calibrated using offline marginal action utilities, enabling the same trained adapter to support different communication budgets without retraining. We evaluate CERA on GR00T N1.7 and π0.5 across four LIBERO suites and four RoboLab tasks. CERA reduces communication by 10–13× while preserving near-original task success, and action-aware refinement allocation improves closed-loop success by 8 percentage points over reconstruction-based allocation at the same communication budget.

Highlights

Key Contributions

01

Plug-and-play split interface

Compresses the cloud-to-robot conditioning representation while preserving the pretrained VLM, action head, and original input pathways.

02

Base–refinement representation

Retains a compact base code for every unit and adds selective refinement under an adjustable budget M.

03

Action-calibrated allocation

Uses offline marginal action utilities to prioritize the refinements that best preserve downstream actions.

Approach

CERA Framework

+
Base codes are always transmitted · refinement codes are budget-controlled

CERA reorganizes the VLM output into interface units and encodes each unit into a base code and a refinement code. At inference, the cloud computes an action-calibrated priority for every unit, transmits all base codes and up to M selected refinements, and the robot reconstructs the native representation before local action generation.
