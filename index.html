Summary

Abstract

Vision–language–action models rely on large multimodal backbones that are difficult to deploy fully onboard resource-constrained robots. A cloud–edge split offers a practical alternative, but repeatedly transmitting high-dimensional intermediate representations creates a substantial communication burden. We introduce CERA, a Communication-Efficient Refinement Adapter that sends a compact base representation for every interface unit and selectively adds refinement according to predicted action-preservation benefit. Offline marginal action utilities calibrate refinement priorities, allowing one trained adapter to support multiple communication budgets without retraining.

Highlights

Key Contributions

01

Plug-and-play split interface

Compresses the cloud-to-robot conditioning representation while preserving the pretrained VLM, action head, and original input pathways.

02

Base–refinement representation

Retains a compact base code for every unit and adds selective refinement under an adjustable budget M.

03

Action-calibrated allocation

Uses offline marginal action utilities to prioritize the refinements that best preserve downstream actions.

Approach

CERA Framework

+
Base codes are always transmitted · refinement codes are budget-controlled

CERA reorganizes the VLM output into interface units and encodes each unit into a base code and a refinement code. At inference, the cloud computes an action-calibrated priority for every unit, transmits all base codes and up to M selected refinements, and the robot reconstructs the native representation before local action generation.
